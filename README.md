# Personal Student Dashboard
A responsive beginner-friendly BTech mini-project using HTML, CSS and JavaScript.

## Features
- Editable student name
- Task and assignment list with optional due dates
- Mark tasks complete and see progress statistics
- Study timetable with times
- Autosaved notes and dark mode
- Browser localStorage persistence (no account or cloud synchronization)

## How to run
Download and extract the ZIP, then open `index.html` in a modern web browser. No installation or server required.

## Files
- `index.html`: dashboard structure
- `style.css`: styling and mobile layout
- `script.js`: interactions and local storage

This is a frontend demonstration, not a deployed multi-user SaaS backend.
